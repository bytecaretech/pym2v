pym2v is a Python wrapper for interacting with the m2v industrial IoT platform from Eurogard.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `bytecaretech/pym2v` (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
